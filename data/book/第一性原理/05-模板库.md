# 第一性原理：模板库（直接套用）

## 模板 1：一页纸问题推演（最常用）

```md
# 问题陈述（1-2 句）

# 目标与验收（指标/截止时间）

# 不做什么（边界）

# 约束（时间/资源/合规/能力）

# 事实（带来源：数据/样本/日志/访谈）

# 关键假设（必须可验证）

# 机制（为什么这会带来结果：因果链）

# 方案（任务卡：Owner/What/When/Done）

# 验证（指标阈值/周期/止损与回滚）

# 复盘（时间点/输出物）
```

## 模板 3：机制一句话

```text
因为（底层事实/心理规律/技术机制）________，
所以（动作/方案）________ 会导致（关键指标变化）________。
```

## 模板 4：验证设计（最小验证）

| 假设 | 验证方式 | 成功阈值 | 失败阈值 | 周期 | 负责人 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

## 模板 5：方案任务卡（4W）

| Owner | What（交付物） | When（截止） | Done（验收） |
|---|---|---|---|
|  |  |  |  |

## 优先级（你先用哪几个模板）

| 优先级 | 模板 | 使用场景 |
|---|---|---|
| P0 | 一页纸问题推演 | 80% 的工作问题都能用 |
| P1 | 三栏表 + 机制一句话 | 争论大、方向不清时 |
| P2 | 验证设计 + 任务卡 | 需要落地执行与实验时 |
