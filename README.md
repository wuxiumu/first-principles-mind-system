# FirstPrinciples-MindSystem
一款基于第一性原理、目标拆解、自我管理思维搭建的前端可视化成长系统，融合7天管理高手思维，沉淀个人认知、做事逻辑与成长感悟，极简高级UI，主打思维结构化、认知可视化。

  二、项目底层逻辑（必须写进项目，是灵魂）
1. 本项目第一性原理（你写在项目首页）
   剥离表象，回归本质；剔除情绪，只留逻辑；一切复杂问题，拆解为最简单不可拆分的底层要素。
   所有管理、成长、做事，只遵循三条底层公理：
1. 结果 = 目标 × 行动 × 时间
2. 复杂问题 = 最小单元拆解
3. 个人成长 = 刻意练习 + 高频复盘
2. 你个人感悟（我给你写好，直接放进项目About页）
   我过去做事混乱、盲目忙碌、被情绪裹挟。后来明白：人最大的能力，不是努力，而是结构化思考。
   学习管理、学习第一性原理，不是为了高深理论，而是为了：
   把混乱的事变清晰，把复杂的事变简单，把模糊的目标变可执行。
   本项目不只是前端作品，更是我个人思维的沉淀容器。我用代码固化我的思考，用页面记录我的成长，用逻辑约束我的行为。
   代码可以迭代，思维永远进化。
   三、技术栈（轻量化、好看、上手快、适合个人项目）
- 框架：Vue3 + Vite（轻、快、适合个人项目）
- UI：TailwindCSS + 极简自定义暗黑高级风
- 图标：Iconify
- 数据存储：LocalStorage（无需后端、开箱即用）
- 动画：原生CSS过渡，高级简洁不花哨
- 部署：Github Pages 免费部署
